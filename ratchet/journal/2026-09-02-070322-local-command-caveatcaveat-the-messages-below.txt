  Half one: the conformance frame rule (already proved, now named)

  StateOk reads the heap, the frames and the frame stack. ctl and kont are the
  whole frame, and a change confined to the frame can't disturb the description
  — frameOnly + StateOk_frame, whose proof is StateOk_reCtl's. Worth recording
  next to it why ctl/kont are the only frame: the run-quantifying components
  (denM's arrow arms, AsmsOk) survive them for a sharper reason than not looking
  — applyIn/sendIn overwrite both, so the run a call denotes is literally the
  same run from both machines.

  Half two: "and nothing more" — the part that was missing

  Every component was a lower bound. Three components, not the one I expected:

  - MethodsExact — every method installed anywhere in the heap is an axiomatized
    builtin, a prelude definition, or a name κ records. The model's own two
    discriminators (MethodDef.builtin, .fromPrelude) do all the work, so it
    needed nothing new in RubyCore. Measured before stating it: zero exceptions 
    at the booted heap.
  - NameFreeOk — because MethodsExact isn't enough. It allows a prelude method,
    and bareName needs x to resolve to nothing; "not the user's" is not "not
    there". So the prelude escape is dropped on a fixed three-name list
    (lambda/proc/x) and the claim is localised to the receiver's chain.
  - SelfLive — forced by that transport, and it closes a gap nothing had named:
    StateOk never said self is a real object. classOf reads the total Heap.get,
    so at a dangling self an allocation changes what self is an instance of.
